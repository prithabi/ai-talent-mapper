# AI Talent Mapper

### Find Right Talent. For Right Role. For Right Impact.

AI Talent Mapper is an AI-powered talent assessment and role-matching platform designed to discover an individual's natural intelligence, strengths, work style and potential.

## Vision

Connect every individual to their natural intelligence and the right opportunity for a better world.

## Core System

AI Talent Mapper follows a structured assessment and intelligence-mapping process:

1. Candidate Registration
2. Psychometric & Behavioral Assessment
3. AI Scoring & Analysis
4. Intelligence Code Mapping
5. Talent Profile Generation
6. Role Compatibility Index (RCI)
7. Team Synergy Analysis
8. Career & Role Recommendations
9. Automated PDF Report

## Intelligence Code Framework

The current prototype includes six Intelligence Codes:

- EI2 — Explorer / Discovery Intelligence
- 9HY — Agile / Kinetic Intelligence
- 80L — Visual-Spatial Intelligence
- 021 — Social-Linguistic Intelligence
- 23BR — Logical-Analytical Intelligence
- D1 — Self-Reliant / Intervention Indicator
